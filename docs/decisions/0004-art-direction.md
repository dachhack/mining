# 0004 — Art direction: pixel art, details open

Date: 2026-11-18. Status: accepted.

The owner chose pixel art as the direction and left the details open. M3 ships flat colours and simple icons. The renderer takes each block type's appearance from data, so moving from flat colours to a pixel-art texture atlas in M6 is a change of assets and data, not of rendering code. Each hazard tell uses a shape or pattern as well as a colour from M3 onward.

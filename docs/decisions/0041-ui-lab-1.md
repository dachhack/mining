# 0041 — UI lab 1: a start screen, and plain blocks with no turns

Date: 2026-11-21. Status: implemented (issue #116). No game rule, data number or golden hash changes; `ENGINE_VERSION` stays 0.4.0.

## What

- **A start screen.** The app opens on "Game" (the phone preview, unchanged) and "Lab 1". The screen is chosen by the address's hash (`#game`, `#lab1`, `#lab1/110` for seed 110), so the phone's back button works. Changing screens reloads the page, so no screen has to tidy up after another. The game has a "‹ Start screen" bar above it. Later labs add a button and a hash in `src/app/launcher.ts`.
- **Lab 1** (`src/app/lab/`): the generated cube of a seed (`createRun`, as the game makes it), drawn from above as each square's top block (`topBlockAt`; trees are ignored, so the block under a tree shows). Each block kind has a painted texture as well as a colour, so kinds differ by pattern too. A square lower than a face neighbour has a soft shadow along that edge; deeper squares are also a little darker. A tap mines if `mayMine` allows it; a refused tap shakes the map, flashes the higher neighbours and changes nothing. A counter above the map shows the blocks dug and each resource collected. No turns, AP, fuel, hazards, crew or forecast.

## Choices

- **A pure engine function, `labMine(state, x, y)`** (`src/engine/lab.ts`), rather than mining in the app. It applies `mayMine`, removes the top block, returns the yield from `BLOCKS`, and collapses a cavern under the block (`collapseSpaceUnder`), as the real mine does, so the square drops exactly 1 and the level rule holds. It works on a copy and never changes its input. Nothing in the game calls it.
- **The lab's state lives in `src/app/lab/labWorld.ts`:** the cube, a depth table, and the counts. It is not saved; "New world" starts another random seed. The game's saved run is untouched.
- **Water, lava and gas from a breached pocket are ignored** in the lab: they stay in the cube, but nothing is drawn or spreads.
- **The lab map fills the screen** under the counter, so it is taller than wide; it has its own small camera (`labCamera.ts`) rather than the game's square one. Drag, pinch and the wheel work as on the game's map.
- **Look numbers** (texture size, shadow width and strength, cue timings) are presentation, not gameplay, so they live in `src/app/lab/labLook.ts`, as the game map's look lives in `src/app/map/palette.ts`.
- **The e2e tests now open the game at `/#game`**, since `/` is the start screen.
